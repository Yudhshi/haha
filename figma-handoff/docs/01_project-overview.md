# 01 プロジェクトの全体像

## 何を作っているか

Honda RoadSync（バイクとスマホをつなぐアプリ）のサービスサイト PH2 の LP。LP には「ON-RIDE（走行中の機能）」「OFF-RIDE（走行前後の機能）」「対応モデル」「メーター&ハンドルスイッチ」などのセクションがある。Goodpatch のデザイナー（このパックの持ち主）が Figma で担当している。

この 1 か月の作業の中心は 3 つ：

1. **「使い方」モーダル（ナビ・電話）**
   LP の「ナビゲーション」「電話」セクションから開く、操作手順の紹介モーダル。メーター・手元のスイッチ（手把）・スマホの 3 機器を並べ、1 手ずつ「次へ」で進む。序章（-0）→ 6 手（ナビ）／5 手（電話）。PC・TAB・SP × Dark・Light。
   - PC には「右からのドロワー案」（画面右半分に出し、左の LP 写真は見える）もある。
2. **「Gen1 と Gen2 の違い」比較モーダル**
   2 ページ構成：① マップ表示（Gen2 はメーターに地図まで出る）② 手元のボタン（Gen2 は左手のボタンでナビ・音楽・電話などを切り替え）。PC/TAB/SP × Dark/Light、各 24 枚。
3. **入口（ボタン位置）の検討**
   - 「使い方を見る」ボタンを LP のどこに置くか（Navigation ページ）。
   - 「Gen1 と Gen2 の違いを見る」ボタンを「対応モデル」セクションのどこに置くか（比較ページの「ボタン位置」section）。
   - 案11「追従ピル」は動く原型あり（PH2 _ Dark を土台に、対応モデル〜メーター&ハンドルスイッチの間だけ画面下に浮く）。

ほかに、テーマ切替（Dark/Light）のアイコン検討（車灯スイッチ案）と、ON-RIDE Light の写真の画質調整をした。

## 用語

| 用語 | 意味 |
|---|---|
| Gen1 / Gen2 | 対応メーターの世代。Gen2 はメーターに地図を出せる、左手の機能切り替えボタンがある |
| 手把（てば）／switch | ハンドルスイッチ。中央の ✓ はスティック（上下左右に倒す＋押す）、周りの矢印は印刷 |
| FUNC ▲▼ | Gen2 の左手の機能切り替えボタン（ランチャー）。手把の部品には描かない |
| 序章（-0） | 使い方モーダルの最初の画面。「見てみる」で 1 手目へ |
| ドロワー案 | PC の使い方モーダルを右半分に出す案（image 9 参考） |
| 追従ピル | 案11。画面下に浮くボタン（Apple「iPhoneの全モデルを比較する」型） |
| UX 4 軸 | 気づく・わかる・ジャマしない・迷わない（案の評価軸） |
