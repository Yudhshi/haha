**use_figma の落とし穴**
- **コンポーネント variant 内の子ノードは `remove()` できない**（"Removing this node is not allowed"）→ `visible=false` で退避する
- `createAutoLayout()` / `createFrame()` は**既定で白フィル**。ネストした行コンテナの `fills=[]` を忘れると白い箱が中身を隠す
- **進捗ドットのアクティブ表現は「幅 16 vs 6 ＋ fill」**。opacity をいじっても先頭のピルは動かない。ドット数を変えたら `layoutSizingHorizontal='HUG'` にして中心（PC 720／SP 195）へ置き直す
- 表紙のテキストを y でソートすると **(値, ラベル) の順**（値 y=340／ラベル y=344）。ラベルに値を書き込む事故のもと
- `bus` レール：枠を 638 に縮めても中の Rectangle / dot-anim は 1152 のまま。子も resize＋`clipsContent=true` の両方が要る
- **`flowStartingPoints` は放置すると勝手に増える**（未接続フレームを作るたび Figma が足す。27 個まで膨れた）。作業後に明示代入
- `textAutoResize` の変更にも**フォントのロードが必要**
- `swapComponent()` は PC↔SP でも使える。後で `resize()`（SP: phone 104×231.11／meter 314×188.4）
- カード高さを揃えるのに `FILL` スペーサーは効かない（itemSpacing を食う）。**テキストを固定高にして HUG** が確実
- `get_screenshot` が "invalid node selection" を返すことがある → `use_figma` 内で `await node.screenshot()` すれば通る
