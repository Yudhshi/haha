**2026-09-17 実測したクリア領域**（安全域の角 72,72 を起点に、人物に被らない幅。
A/B 2枚スクショの差分＝前景写真 `2968:74964` を visible 切替して PIL で計測）

| y | 人物の左端 x | 72 からの使える幅 |
|---|---|---|
| 72–140 | 327 | **255px**（ヘルメット） |
| 150 | 302 | 230 |
| 170–200 | 271–274 | **200px**（肩） |
| 220–260 | 255–261 | **183px**（背中・腕）← 最狭 |

**結論（重要）**：クリア領域は上が広く下が狭い台形。y72–360 に **幅183px の縦長コリドー**はあるが、
297px 幅の横長パネルは**どこにも収まらない**。現状は右 114px（ズーム列・FUEL・時計は 100%、Map は下部で最大 57%）が常時不可視。
- 同じ比率(297:183)で完全に見える最大は **199×123 @ (72,72)**（現状の 67%）。
- 現パネルを活かすなら人物を **右へ 114px** 相当（＝約12%縮小＋右50px 等）動かす必要がある。

計測レシピ：前景写真を `visible=false` にして 720px スクショ2枚 → `ImageChops.difference` → 行ごとに閾値12超の最左 x。

## 2026-09-17 追記：4案の試作

セクション **`3018:22314`「遮蔽対策 4案（A/B/C/D） — 2026-09-17」**（page `1041:3973`、x=99500 y=37337）に
PC gen2 Light の複製4枚を並べた。各クローンの frame ID：
**A `3018:22315`** / **B `3018:22534`** / **C `3018:22753`** / **D `3018:22972`**

- **A** ガラスを前景写真の上へ（`frame.insertChild(photoIdx+1, glass)`、x/y は 72,72 のまま）＋ plate の fill opacity 0.72→0.80。
  plate は元から opacity 0.72 + BACKGROUND_BLUR 18 なので、前に出すだけで人物が透ける。**追加作業ほぼゼロで地図100%。最有力。**
- **B** 写真2枚に `x'=0.88x+144.6, y'=0.88y`。**等倍スケールなら IMAGE FILL(scaleMode FILL) のクロップは変わらない**のが肝。
- **C** `glass.rescale(199/297)` → x=72,y=72。中身ごと縮む。文字はかなり小さい。
- **D** ズーム列/FUEL/時計/Backボタン/Standard を hide、`row51.insertChild(0, map)` で Map を左へ、`row50.x=4`、
  glass+plate を 187 幅に resize、右端に GRADIENT_LINEAR の `isMask=true` 矩形でフェード。
  **落とし穴**：187 幅だと fade 開始が frame x=210 になり、速度「57」が溶ける。ギア/速度を左詰め（meter x=1.8 / 30.8）にして回避。

## 案B のトレードオフ（実測）

前景切り抜きの footprint は原寸で **x 150..718 / y 60..708** — つまり**車体はすでにフレーム右端(720)に接している**。
よって右へ動かせば必ず前輪が切れる。

| 目標 | 車体を切らずに済む最大スケール | シフト | 88% 時の切れ幅 |
|---|---|---|---|
| パネル全体(右端369)を出す | 0.73 | +189 | 62px |
| **地図だけ(右端330)を出す** | **0.82** | **+127** | 23px |

現在の B（0.88 / +144.6）は**前輪が56px欠ける**。クリアランスも y=216 でちょうど 0px。
**地図だけが目的なら 0.82/+127 で車体を切らずに済む** — パネル全体を狙うから切れるのであって、
救っている右端36px（ズーム列・FUEL・時計）はいずれも装飾。

## 案の採否（2026-09-17）
検討セクション `3018:22314`「遮蔽対策 案A / B / C / G」。**D・E・F はユーザーが却下**（D=遮蔽前提の再構成、E=地図を独立カード化、F=地図だけ最前面ブレイクアウト）。
生存: A `3018:22315` / B `3018:22534` / C `3018:22753` / **G `3032:22519`**。

**案G = メーターを右・Arrival チップを左上に入れ替え**（ガラス x72→351、チップ x538→72、y は両方 72）。実測の効き:

| | 左（現状） | 右（案G） |
|---|---|---|
| パネル全体の隠れ | 24.7% | **18.2%** |
| **地図の隠れ** | **39.0%** | **3.7%** |

右に置くと遮蔽はヘルメット＋ハンドル/ミラーになり、食われるのが**パネル左側＝TBTテキスト**に変わる。
地図はパネル右側にあるのでほぼ無傷。さらに、左配置では常時不可視だったズーム列・FUEL・時計（パネル内 x258–294）が**右配置では全部見える**ようになる。
右側で完全クリアにできる最大サイズは **203×125 @ (445,72)**（左の 199×123 とほぼ同じ）。

**案G Dark** `3038:22519`（元は gen2 Dark PC `2968:75711`）も同じ入れ替えで作成済み。
構造の違いに注意: **Light は前景写真とチップがフレーム直下**だが、**Dark は両方 `Visual` の中**にある。
座標系は Visual が 0,0 の 720×720 なのでフレーム座標と一致し、操作（glass.x 72→351、chip.x 538→72）は同じで済む。
遮蔽は同一アセット・同一位置なので数値も Light と同じ（地図 3.7%）。
セクションは `3018:22314` に A `3018:22315` / B `3018:22534` / C `3018:22753` / G `3032:22519` / G Dark `3038:22519` の5枚。
