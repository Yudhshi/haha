**use_figma の落とし穴（追加）**
- **画面インスタンスの差し替えに `swapComponent()` を使ってはいけない。** swap は縮んだインスタンス枠を保つので、続く `resize(native)`→`rescale()` が中身を**二重に縮める**（実測 58%）。正解は **`comp.createInstance()`（native で生まれる）→ `rescale(目標/native)` → x/y・opacity・effects を復元 → 旧を remove**。z順は `insertChild(旧index, 新)` で保つ
- **`flowStartingPoints` はフレームを複製するたび Figma が勝手に足す。** 56 枚作ったら 61 個に膨れた。作業後に必ず明示代入
- **instance の子ノードは `visible` を変えると参照が無効になる**（`The node with id ... does not exist`）。名前・座標など必要な値は**変更前に読み切ってから**まとめて mutate する
- **刻印 `mark-*` は fills ではなく strokes で描かれている。** 色を変えるときは `node.strokes` を差し替える
- **`findAll()` はノード自身を含まない。** フレーム自身の `AFTER_TIMEOUT` を数え落として「到達不能」の誤検出を出した。到達性を見るときは `[f, ...f.findAll(...)]`
- **TEXT を `textAutoResize='HEIGHT'` にしてから `resize(w, 小さい値)` すると高さが伸びない。** `NONE` → `resize` → `HEIGHT` の順で当て直す
- 同名ノードを持つ複数対象をループで dict に入れると**キー衝突で上書きされる**（`modal` という名前が2つあり、④の値が③を潰した）。ID をキーにすること
- section の子の x/y は**セクション相対**。`absoluteBoundingBox` は page 絶対
