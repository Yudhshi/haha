## Arrival チップの統一（2026-09-17）
`chip · arrival` は Light/Dark で**幾何・フォント・余白・文字サイズは完全一致**、違うのは色と線幅だけだった。
| | Light | Dark（旧） |
|---|---|---|
| fill | #F2F5FA 62% | #0B0E13 52% |
| stroke | 白 85% / 太さ **1.0×** | 白 34% / 太さ **1.5×** |
| inner shadow | 白 a0.90 | 白 a0.28 |
| drop shadow | 黒 a0.18 | 黒 a0.35 |
| 文字・アイコン | #212121 | #FFFFFF |

線幅の 1.0 対 1.5 はテーマ差ではなく**元データ由来の不整合**。チップは Light/Dark とも同じ空の上に乗るので、
ユーザー判断で **Light の白ガラスに統一**。

**やり方**: 値を個別に書き写すのではなく **Light 側のチップノードを `clone()` して Dark の同じ親・同じ index に `insertChild` し、
元のチップを `remove()`** する。これならブレークポイントごとにスケール済みの線幅（1.0 / 1.033 / 0.842）や
ぼかし半径・シャドウ半径まで自動で揃う。x/y は差し替え前の値を代入して位置を保つこと。

差し替え後のチップ: PC `3043:22806` / TAB `3043:22809` / SP `3043:22812` / 原本12129 `3043:22815`。
※ 原本 `12129` (`3038:22519`) のチップも同時に統一済み。
