**结构**（不是普通图片，是手工搭的模拟景深堆栈，自下而上）：
1. RECTANGLE「1」— 基底清晰图，`scaleMode=FILL`，App 界面已烘焙进这张图里（不是独立图层）
2~5. GROUP「2/3/4/5」— 每组 = 亮度遮罩 frame（白底 + 黑色模糊矩形盖住手机）+ 同一张图的 CROP 副本加 LAYER_BLUR
   - R3 微散焦（遮罩焦点 270x530 / blur60）→ R7 中散焦（430x690 / blur100）→ R12 远散焦（640x900 / blur120）
   - GROUP 5 用线性渐变遮罩只露底部袖口 → 近景散焦 R18
   最终可见：远角=R12，中圈=R7，近圈=R3，手机=基底清晰层，底部=R18。

**基底层和散焦层用的是不同 imageHash**（基底更新过、散焦板仍是旧图），但实测色调几乎一致（ΔL≈2-5），
不必替换；改滤镜即可。

**2026-09-11 定下的滤镜分级**（Figma image filters，-1~1）。基底层「1」保持全 0 —— 它是焦平面，
用户已经自己调过，动它会改到 App 界面颜色。

| 层 | dark: exp/con/sat/temp/high/shad | light: exp/con/sat/temp/high/shad |
|---|---|---|
| R3  | -.05 / -.02 / -.05 / 0    / -.04 / -.02 | -.04 / -.02 / -.06 / 0    / -.05 / 0    |
| R7  | -.11 / -.05 / -.11 / -.03 / -.09 / -.04 | -.08 / -.04 / -.12 / -.02 / -.09 / -.02 |
| R12 | -.18 / -.09 / -.18 / -.06 / -.15 / -.07 | -.14 / -.07 / -.18 / -.04 / -.13 / -.04 |
| R18 | -.26 / -.05 / -.24 / -.05 / -.20 / -.12 | -.22 / -.04 / -.22 / -.03 / -.17 / -.08 |

**Why:** 原本背景左上 L=151，dark 版屏幕只有 L=69 —— 背景比主体亮 2.2 倍，视线被抢走。
分级压暗后背景 L→122，屏幕 L 不变。light 版屏幕 L=188，靠压 highlights 拉开与墙面的差距（151→128）。
**How to apply:** 越远的散焦层，exposure/saturation/highlights 压得越狠（大气透视）；
shadows 走负值而不是正值 —— 正值会把背景提成灰雾，反而削弱暗色屏幕的存在感。
temperature 只在远层给负值，近层（贴着手指）保持 0，否则肤色会发青。

**散焦板是旧机型（圆角刘海），基底是新机型（Dynamic Island）** —— 这是最容易踩的坑。
基底 1277x1232 / FILL，散焦板 3064x3064 正方形 / CROP，几何不同，不能直接换 imageHash。
补救靠遮罩：只要焦点遮罩把「新旧机身的并集」整个包进 core，旧机身就不会露出来。

**遮罩几何（2026-09-11 按新机型重新对位，dark/light 同一套）**
- 用 dark 底图与 light 底图做差分，白色连通域就是屏幕精确轮廓（两版机身零差异，只有屏幕内容不同）——
  这是量新手机位置最干净的办法。
- 屏幕（旋转 17.7° 坐标系）191x483，机身 ≈ 212x501，中心 (342, 281)。
- 焦点矩形必须 = 机身 + 每边 blur 半径，否则羽化带会把机身本身吃进去。
  2号 270x530 时左右只剩 29px、上下只剩 14.5px 余量（blur 60）→ 机身内 12.85% 面积混入旧机身，
  峰值 alpha=144 在右上角 (518,74)。改成 **332x621** 后污染降到 0.00%。
- 三个焦点矩形保持同心 (342,281)、同角度 -17.7°；3号 430x690(blur100)、4号 640x900(blur120) 余量够，只对心。
- 设 relativeTransform 前必须先 resize()，resize 会重置 transform。
  rt = [[cos,-sin, cx-cos*w/2+sin*h/2],[sin,cos, cy-sin*w/2-cos*h/2]]
- 修好后 dark 的 GROUP「2」opacity 已从 0.2 恢复 1.0（0.2 原本只是为了压旧机身重影的 workaround）。
- 实测景深接力健康：机身边 0-15px 全清晰 → R3 在 90px 处峰值 0.59 → R7 在 165px 处 0.75 → 210px 后 R12 接管。
